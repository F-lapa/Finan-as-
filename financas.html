Open Finance

Conexão automática com bancos brasileiros via Open Finance / Open Banking.

Este app roda 100% no seu navegador (sem servidor). Por isso a conexão direta com bancos não é possível só com este arquivo HTML.

Para extrato automático de verdade seria preciso:

  • Backend seguro (API própria)
  • Certificados e parceria com iniciadora/Open Finance
  • Consentimento do usuário no banco

Enquanto isso, o fluxo mais automatizado disponível aqui é:

  1. Exportar extrato no app do banco (CSV/OFX/texto)
  2. Colar em Importar — categorização, regras e anti-duplicata entram em ação
  3. Usar recorrentes + lembretes para o que se repete todo mês
